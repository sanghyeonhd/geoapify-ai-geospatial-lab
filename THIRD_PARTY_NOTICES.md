# Open-source attribution

This project builds on the **idea and request workflow** in Geoapify's official
Node.js geocoding sample:

- Upstream repository: https://github.com/geoapify/maps-api-code-samples
- Starting example: `node/geocoding-with-RPS-limit-respect/geocode.js`
- License: MIT; original copyright (c) 2025 Geoapify.
- Attribution is retained in `LICENSE`.

The batch geocoding example here is **rewritten and extended** with an environment-
loaded key, per-run request budget, argument checking, and deterministic unit tests.
The broader MCP client, REST API wrapper, CLI, and research documentation are
new additions. This project is not an official Geoapify product.

Geoapify OpenAPI specifications used as technical references:
https://github.com/geoapify/geoapify-openapi-specs (MIT).
